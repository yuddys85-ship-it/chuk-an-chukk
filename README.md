# Chuk an Chukk

Live Social App for Pi Community

---

## 🚀 Features

- Login with Pi Network
- Pi Browser Support
- Wallet Dashboard
- CHUK Exchange
- Earn System
- Payment with Pi
- Progressive Web App (PWA)
- Install App on Android
- Offline Cache Support
- Responsive Mobile Design
- Chrome & Pi Browser Compatible

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/chuk-an-chukk.git
```

---

## ▶️ Run Local

Open:

```txt
index.html
```

Or use local server:

```bash
npm install
npm run dev
```

---

## 🌐 Deploy to Vercel

1. Upload project to GitHub
2. Open Vercel
3. Import GitHub Repository
4. Deploy

---

## 🔥 Pi Browser Setup

Add Pi SDK:

```html
<script src="https://sdk.minepi.com/pi-sdk.js"></script>
```

Initialize SDK:

```javascript
Pi.init({
  version: "2.0",
  sandbox: true
});
```
